# Skydive Mobile

Expo iOS + Android client for Skydive. Assignment project: talk to your agents from a phone, without Skydive's backend — we hold the API key on a BFF later.

This repo is built as small pull requests. See [docs/PR_PLAN.md](docs/PR_PLAN.md) after the architecture PR lands.

## Status

Empty on purpose. Architecture and ADRs land first; UI and backend follow on feature branches.
