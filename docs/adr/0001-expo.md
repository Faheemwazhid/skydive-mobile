# ADR 0001 — Expo + React Native

Status: accepted  
Date: 2026-08-27

## Decision

Ship iOS and Android from one Expo (current SDK) + TypeScript + Expo Router codebase.

## Context

Assignment time is finite. Skydive's own surface is TypeScript. A reviewer should read the app without a language jump.

## Alternatives

- Swift + Kotlin: native depth, doubles the work.
- Flutter: polished, slower review at a TS company.
- iOS-only: leaves Android out of a dual-platform product.

## Consequences

EAS for builds later. No pixel-identical UIKit. Inter for headlines until Aeonik is licensed.
