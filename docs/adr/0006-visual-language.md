# ADR 0006 — Native translation of the web brand

Status: accepted  
Date: 2026-08-27

## Decision

Phone patterns (tab bar, sheets, full-screen thread) with Skydive brand: off-white `#F7F7F7`, dark grey `#262523`, Inter, seven velvet characters, dusk covers. Not a three-column web layout squeezed onto a phone. Not a redesign that only keeps the palette.

Reference shots: `~/Documents/skydive-mobile-app/web-reference/` (not in this git repo; large binaries). Brand tokens: `~/Documents/skydive-brand/BRAND.md`.

Aeonik is commercial. Inter is the in-app headline face unless we have a license.

## Consequences

Team is roster + feed, not the web home-as-feed. Chat is list → thread, not a web sidebar. Profile is header + chats, not four empty web tabs.
